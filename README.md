# Excavation

Fabric mod for Minecraft 26.2. It adds three enchantments: Excavation (Pickaxe), Excavation (Shovel), and Excavation (Hoe). Each supports levels I-III and can be combined with other enchantments.

## Use

Hold an enchanted tool and tap the sneak key five times within 1.2 seconds to cycle its area mode. The modes are Off, 3x3, 5x5, and 7x7, limited by the enchantment level. Mode is remembered per hotbar slot. A subtitle and sound confirm each change; selecting an enchanted tool shows its current mode. White outlines preview the blocks in the area.

## Recipes

Craft an Excavation I enchanted book by shapelessly combining any wooden, stone, iron, golden, or diamond pickaxe, shovel, or hoe. Netherite tools are intentionally not included. Combine three identical Excavation books in a horizontal row to craft one book of the next level. Apply books to tools with an anvil.

## Build

Requires Java 25. Run `./gradlew build`; the mod jar is created in `build/libs/`.
